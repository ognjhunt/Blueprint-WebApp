## Scope

- Public pages explain the buying journey and evidence used as needed.
- Existing approved robot illustrations, reduced-motion handling and privacy controls remain.
- Buyer intake starts with a description; video, frequency and buying plans can be added progressively. No budget is required for free assessment.
- Reviewed partner applications distinguish installation/support from technology access.
- The owner workspace records requirements, options, versioned proposals, selection, pilot agreement and customer-reported outcomes in Blueprint's existing datastore.
- Admin tools populate proposals and record agreement references; an API alone is not the operating interface.
- Selection is not contract award. The customer and delivery partner agree physical work directly.
- Customer observations remain separate from Pipeline-owned scientific verdicts and Physical Outcome Joins.

The existing beta remains free. This implementation adds no assessment fee, success fee, checkout, provider spend or automatic contract award. Existing site recording, training, anonymized-card and account permissions remain binding. Historical records, previous legal versions, API identifiers and scientific evaluation artifacts retain their contracts.
