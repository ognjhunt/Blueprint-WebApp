# Capturer Beta Guide — retired

**Retired on 2026-10-13.** Blueprint no longer runs a capturer network. A site films its own
job with a phone, or asks Blueprint staff to film it during an in-person visit (currently in
the Austin metro).

- The public guide at `/beta/capturer-guide` now redirects (301) to
  [Show us a task](https://tryblueprint.io/contact/site-operator).
- Sites: read [SITE_OPERATOR_BETA_GUIDE.md](./SITE_OPERATOR_BETA_GUIDE.md).
- Robot teams: read [BUYER_BETA_GUIDE.md](./BUYER_BETA_GUIDE.md).

Footage filmed by Blueprint staff is handled exactly like footage a site films itself: the
same uses, sharing limits, retention and rights described in the
[privacy policy](https://tryblueprint.io/privacy).

The previous guide's content (capturer payouts, assignments and review states) is in this
file's git history.
