teams. These records live in `controlledDevelopmentOffers`, expire, and never
enter qualified site supply. A publication binds capture and task digests, the
native canary receipt, exact policy interface, execution profile and one episode.

rights evidence, not a team assertion. The existing account, early access,
entitlement, signed quote, funding hold and Pipeline admission gates still apply.

outcome and receipt digests. The team's existing result API returns this report;
another team cannot read it. Development results cannot upgrade site matching,
physical-success claims or qualification. Official provider cost can remain
pending after execution and teardown are proven; the result explicitly says so.

native execution/scoring receipts, private result readback, owner isolation and
provider teardown. Source integration and contract checks alone do not prove
those live artifacts. The live proof receipt is recorded separately after the run.
