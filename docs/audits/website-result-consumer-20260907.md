## Arithmetic and independent expectations

Paired cohort: exactly one learned episode for each candidate at the same nonempty cell ID and finite seed, with explicit interpretability true and a boolean deterministic outcome on both. Ambiguous duplicate candidate/cell/seed or episode IDs do not enter the paired calculation. Records and their failure evidence remain visible.

Let `a` be A-only successes, `b` B-only successes, and `N` mutually scorable pairs. Signed A-minus-B difference is `(a-b)/N`; the display uses its magnitude and corresponding candidate identity. The two-sided exact sign test is `min(1, 2 * sum(C(a+b,k), k=0..min(a,b)) / 2^(a+b))`. With no discordant pairs its p-value is not informative and is displayed as unavailable. Wilson intervals beside overall candidate rates apply only to their own marginal denominators, not to the paired difference.

| Case | Independently specified expected result |
|---|---|
| Supplied ten-cell defect | A overall 2/6, B overall 4/6; shared N=2, A-only=2, B-only=0; A has +100 pp observed paired success; p=0.5. Former headline was B +33 pp. |
| Candidate order or cell order reversed | Same A direction, 100 pp magnitude, N=2, p=0.5. |
| Disjoint validity sets / no matched episodes | N=0; no direction, delta or p-value. Marginal observations do not substitute. |
| Unequal denominators | A=1/2, B=1/1 overall; shared sole pair favors B, +100 pp, p=1. |
| All ties / one tied sample | Paired delta 0, no candidate leader, no discordant pairs, p unavailable. |
| Unknown/null/false interpretability; absent score/outcome/binding | Excluded from arithmetic; unknown/gaps remain visible. |
| Duplicate A record at cell 0 plus valid A-failure/B-success at cell 1 | Only cell 1 is comparable; B +100 pp, N=1; A's failure remains in denominator. Duplicate records are shown as ambiguous. |
| Verified score correction fixture | Nine mutually interpretable pairs all succeed for both after correction; N=9, bothSucceeded=9, delta=0, no discordance. Original publication preserved. |

The statistical tests use literal expected values, not the production helper to manufacture an expected result. Diagnostic ceilings remain explicit even when p<0.05.
